# LGS Website

Official website for **LGS Mineral Assay Laboratory**, a laboratory under **LGS African Group Company Limited**.

## About

LGS provides mineral analytical and metallurgical testing services for mining, mineral exploration, and mineral-processing operations.

## Pages

- **Home** - Company introduction and key services
- **Services** - Mineral analysis and metallurgical testing
- **About Us** - Company vision, mission, and values
- **Pricing** - Quote-based laboratory services
- **Contact Us** - Location, email, WhatsApp, and enquiries

## Main Services

- Gold (Au) Analysis
- Silver (Ag) Analysis
- Copper (Cu) Analysis
- Sulphur Analysis
- Carbon Activity Testing
- Cyanide Leaching Tests
- Leaching Parameter Optimization
- Metallic Screening & Gold Evaluation
- Technical Assistance & Consultancy
